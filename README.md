# 땅폴레옹 · 남양주 부동산 브리핑

상호: 땅폴레옹 / 센타부동산 · Tel. 010-8848-7727

`npm run build`로 Cloudflare Worker 배포 결과를 `dist/server/index.js`에 생성합니다. 의존성 설치는 필요하지 않습니다. `npm test`로 실거래 파싱, 해제 처리, 날짜 및 위치 제한을 검증합니다. `npm run dev`는 4173 포트의 로컬 서버를 시작합니다. 서버 환경변수 `DATA_GO_KR_KEY`, `REB_API_KEY`가 필요합니다. 키를 소스나 HTML에 넣지 마세요. 운영 키는 Sites의 비밀 환경변수로 등록되어 있습니다.

실거래는 국토교통부 아파트 매매 상세 및 전월세 API에서 법정동 코드 41360으로 조회합니다. 월별 페이지를 모두 수집하며 계약일로 필터링하고 해제 거래는 제외합니다. 기간은 최대 12개월입니다. 전세는 월세 0원인 거래, 월세는 월 임대료가 있는 거래입니다. TOP10은 단지별 최고 금액 또는 거래건수 기준이며 목록 우측 가격은 선택 기간의 최근 거래입니다. 면적 전체를 포함하므로 면적이 다른 거래를 직접 비교할 때 주의하세요.

한국부동산원 검증 코드: 월간 매매가격지수 `A_2024_00045 / 520036 / 100001`, 주간 매매가격지수 `T244183132827305 / 50107 / 10001`, 미분양 `T237973129847263 / 50250 / 10001`. 각각의 자료 기준시점을 화면에 표시합니다. 지표는 남양주시 전체이며 읍면동 필터 수치가 아닙니다. 조회 종료일 이전의 최신 기준시점만 표시하며, 최근 2개 연도 범위에서 조회합니다.

지도는 Leaflet 및 OpenStreetMap, 단지·주변 시설 검색은 Photon 공개 서비스를 사용합니다. 공개 지도에 없는 단지는 위치를 표시하지 않으며, 위치 확인 개수를 안내합니다. 시설 거리는 직선거리, 학교는 주변 학교이며 실제 배정 학군은 아닙니다. KTX 운행·환승은 별도 확인이 필요합니다. 공공 지도 서비스의 제한·누락에 따라 지도와 주변 시설 일부가 없을 수 있습니다.

로고는 사용자가 지정한 땅폴레옹 유튜브 채널의 공식 프로필 이미지입니다. 샘플 추천 매물은 실제 단지의 입지 확인을 위한 예시이며 실제 중개 매물·가격을 주장하지 않습니다. 매물은 브라우저 localStorage에 보관되고 JSON으로 백업·이전할 수 있습니다. 여러 사용자의 매물을 공유하는 서버 저장은 포함하지 않습니다. 현재 사이트는 소유자 전용 비공개로 배포합니다.

개발계획은 남양주시 공식 자료의 광역 이슈이며 선택 단지의 수혜를 판정하지 않습니다. 관리 화면에서 공식 출처·일자와 함께 단지별 개발계획을 추가할 수 있습니다. 인쇄 버튼에서 브리핑을 인쇄하거나 브라우저의 PDF 저장을 사용할 수 있습니다.

## GitHub 공개 소스

API 키는 포함하지 않습니다. Node.js 24 이상에서 `npm run build`, `npm run dev`로 실행하거나 Windows에서 `실행.ps1`을 실행하세요. 실거래 및 한국부동산원 조회에는 본인 API 키를 서버 환경변수로 설정해야 합니다. 정적 GitHub Pages만으로는 서버 API가 동작하지 않으며, 서버 호스팅 또는 로컬 서버가 필요합니다. index.html을 직접 열면 localhost:4173의 실행 화면으로 연결됩니다. 기존 비공개 사이트의 운영 설정은 공개 소스에 포함하지 않습니다. 공식 로고와 공공 데이터·지도는 각 권리자의 이용 조건이 적용됩니다.
